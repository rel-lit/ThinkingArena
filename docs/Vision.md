# 项目愿景

## 目标简述

​	实现一个支持进行不同服务商的LLM参加的跑团游戏/思维实验模拟，可扩展支持不同的”游戏规则“，产出模拟游戏运行过程的LLM生成文本、可视化服务/规则系统服务指令执行记录。接入外部服务，实现音频，视频素材，图片素材的功能扩展。同时整理全局模拟的戏剧化和预期化等网络视频可用的部分，进行视频文案，素材调用。最后结合人工剪辑，产出视频发布B站。

## 指导思想理论

1. 唯一开发者即唯一使用者完全理解把控项目，而非纯粹Vibe Coding

2. 由于Agent协作Coding的不可控性和开发者水平限制，架构水平容易随规模增长下滑，采用现有框架，复制现成代码，嫁接成熟项目比从零开始更好

3. 新建或修改或提出任何一个功能时，都需要去详细参考物联网已有设计和成熟项目，评判价值，而不是反复造轮子
